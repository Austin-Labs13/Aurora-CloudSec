# Aurora CloudSec

## Company Overview

Aurora CloudSec is a fictional managed cloud and cybersecurity services company based in Melbourne, Australia.

The company provides managed IT services, cloud consulting, cybersecurity solutions, and Microsoft infrastructure to small and medium-sized businesses across Australia.

This project simulates the complete design, deployment, and management of Aurora CloudSec's internal enterprise infrastructure.
