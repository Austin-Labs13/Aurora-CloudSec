# Aurora CloudSec

Aurora CloudSec is a fictional managed IT and cybersecurity provider based in Melbourne, Australia.

This repository documents the design, implementation, and management of Aurora CloudSec's internal enterprise infrastructure.

The project is being built to simulate a real-world Microsoft enterprise environment using industry-standard technologies and best practices.

## Objectives

- Build a Windows Server enterprise environment
- Deploy Active Directory Domain Services
- Implement enterprise networking and Group Policy
- Integrate Microsoft Entra ID and Microsoft Intune
- Configure Microsoft 365
- Implement enterprise security controls
- Document every stage of the deployment
