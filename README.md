# Aurora CloudSec

Enterprise Infrastructure | Windows Server | Azure | Microsoft 365 | Cybersecurity

Aurora CloudSec is a fictional managed IT and cybersecurity provider created as a long-term enterprise lab.

The purpose of this project is to design, deploy and secure a modern Microsoft enterprise environment while documenting every stage as a professional portfolio.

This repository demonstrates practical experience with:

• Active Directory
• Windows Server
• Group Policy
• PowerShell
• VMware
• Microsoft 365
• Microsoft Entra ID
• Azure
• Intune
• Microsoft Defender
• Enterprise Security
